# 页面边界（`apps/web/src/pages`）

OpenAIR 规划四个核心页面；**当前实现**为扁平的 `*Page.tsx` 文件，**不强制**立刻改成 `Workbench/` 等子目录，避免无意义的大搬迁。

## 目标目录命名（与产品文档对齐）

| 目标目录名 | 路由关注点 | 当前文件（若有） |
|------------|------------|------------------|
| `Workbench/` | 主工作台：自然语言入口、人机协同、阶段结果、确认与修改 | `WorkbenchPage.tsx` |
| `TaskBoard/` | 任务看板：列表、阶段状态、进度、待办 | `TaskBoardPage.tsx` |
| `TaskDetail/` | 任务详情：全过程、产物、能力调用、失败与回看 | `TaskDetailPage.tsx` |
| `SituationBoard/` | 态势看板：效能、统计、协作、Skill 使用（优先级靠后） | 尚未实现；勿在业务代码写死单一学科场景 |

后续若重构为目录式组件，保持**路由与产品边界**不变即可。
