# OpenAIR 测试体系

本目录定义 OpenAIR 的长期测试证明责任、正式测试资产、测试代码组织和测试运行证据。

## 阅读顺序

| 顺序 | 文档 | 主要职责 |
| --- | --- | --- |
| 1 | **[OpenAIR 测试设计合同](OpenAIR%20测试设计合同.md)** | 定义什么是正式测试资产，以及资产必须声明的受保护结果、证据、判定规则、结论和生命周期 |
| 2 | **[OpenAIR 测试架构](OpenAIR%20测试架构.md)** | 定义长期测试责任，并为不同 `failure_class` 确定 `minimum_owner` |
| 3 | **[OpenAIR 测试代码架构](OpenAIR%20测试代码架构.md)** | 定义已经形成的测试责任在仓库中的代码归属、Suite 组织和依赖 |
| 4 | **[OpenAIR 测试执行基座（Harness）设计](OpenAIR%20测试执行基座%EF%BC%88Harness%EF%BC%89设计.md)** | 定义正式测试或评测怎样获得运行条件，以及怎样保存运行身份和原始证据 |

阅读时先建立正式测试资产的基本合同，再依次理解测试责任、代码归属和运行基座。
