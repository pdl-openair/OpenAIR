## 更新规则

出现新的项目问题时：

1. 先判断它是否只是已有经验的新案例；
2. 如果是，只补来源或代表性证据；
3. 如果现有规则已经不能指导正确动作，再修改对应 `01–09` 正文；
4. 一次性的 Run ID、HEAD、测试数量和事故细节优先留在这里，不进入长期正文。

> **经验正文保持稳定，来源持续积累。**
