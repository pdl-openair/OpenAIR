# OpenTrajectory Eval Governance

本目录只保存 OpenTrajectory Eval Suite 的通用治理规则与复用模板。

- 总入口与当前批次导航：`../README.md`
- 目录、版本、留档与回归规则：`eval-suite-conventions.md`
- 评分、人工复核与 Skill 分类规则：`scoring-conventions.md`、`human-review-guidelines.md`、`skill-category-eval-guidelines.md`
- 可复用模板：本目录中的 `*-template.md`

具体 Skill 的成功标准、Eval 规则和评分口径，应分别维护在对应 Skill 目录中，不在治理文件中重复定义。
