# `constraint-interpretation-skill` Rubric

## 1. 评分尺度

| 分数 | 含义 |
| ---: | --- |
| 4 | 完全满足，可直接供 Phase3 使用 |
| 3 | 基本满足，仅有轻微缺陷 |
| 2 | 部分满足，需要明显人工修正 |
| 1 | 明显不满足，约束解释不可靠 |
| 0 | 不可接受，或触发硬门禁 |

## 2. 评分维度

| 维度 | 权重 | 4 分标准 | 0 分 / 硬性拒绝 |
| --- | ---: | --- | --- |
| 约束分层准确性 | 30% | 硬约束、软偏好、噪声、冲突和待确认项分类准确 | 将歧义、低置信候选值或推测写成 hard filter；从风险推导排除项 |
| 可传递策略完整性 | 25% | 时间、语言、来源质量、明确排除项和标准术语均可供 Phase3 使用 | 明确来源限制或排除项丢失；下游术语不可执行 |
| 降级诚实性 | 20% | 缺口和冲突显式记录，未伪造条件 | 静默消解冲突，或用完整问题伪造 condition |
| 风险标记一致性 | 15% | 约束级风险与汇总风险一致，人工复核状态正确 | 高风险静默丢失，或风险状态与输出行为矛盾 |
| 跨领域泛化 | 10% | 材料、理论方法、AI Agent 与来源规则均能正确解释 | 将方法、机制或软件概念误当材料过滤条件 |

## 3. 人工复核重点

检查软硬分层、显式排噪、来源策略、冲突处理、风险汇总，以及方法、机制和材料是否误分类。

## 4. Judge 限制

Judge 必须给出分项得分、证据片段、扣分点、硬门禁命中、置信度和人工复核建议。Judge 不得覆盖硬门禁。
