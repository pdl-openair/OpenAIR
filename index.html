三大核心机制

针对科研任务周期长、工具分散、证据难追溯、实验反馈利用不足的痛点

🔁 可编排

四阶段是科研活动的组织框架而非固定串行流水线——新的计算结果或实验反馈，可触发平台回到相关阶段补充分析与决策。

🔍 可验证

能力以 Markdown 形态的 skill 承载（SKILL.md + 输入输出契约），registry 统一注册，可独立测试、可回放（replay 模式零密钥跑通全流程）。

🧾 可追溯

每一步产物的来源链全程可回看：哪个 skill、什么输入、什么版本——形成从自主实验到科学发现的可信闭环。

四阶段流水线

干实验（计算验证）与湿实验（制备反馈）在同一流水线内协同闭环

问题建模problem_modeling：从自然语言研究意图到结构化问题
方案设计solution_design：规划器生成候选方案，人在工作台确认
执行验证execution_validation：skill 执行、计算与实验、证据采集
洞察生成insight_generation：证据汇聚、报告撰写、下一轮建议

5 分钟跑起来

Docker 一键启动；replay 模式无需任何模型密钥

git clone https://github.com/pdl-openair/OpenAIR.git
cd OpenAIR && cp .env.example .env
docker compose up -d --build
# 工作台: http://localhost:8080　·　API: http://localhost:8000/health
