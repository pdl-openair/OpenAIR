Three Core Mechanisms

For research that suffers from long cycles, fragmented tooling, untraceable evidence, and underused experimental feedback

🔁 Orchestrable

The four stages are an organizational frame, not a rigid pipeline — new computational results or experimental feedback re-enter earlier stages for supplementary analysis and decisions.

🔍 Verifiable

Capabilities ship as Markdown-shaped skills (SKILL.md + I/O contracts) in a unified registry — independently testable, and replayable with zero API keys.

🧾 Traceable

Every artifact's provenance chain is inspectable end-to-end — which skill, which inputs, which version — closing the loop from autonomous experiments to scientific discovery.

The Four-Stage Pipeline

Dry-lab (computational validation) and wet-lab (fabrication feedback) iterate in one closed loop

Problem Modelingproblem_modeling: from a one-line research intent to a structured problem
Solution Designsolution_design: planner proposes; humans confirm at the workbench
Execution & Validationexecution_validation: skills execute; computation, experiments, evidence capture
Insight Generationinsight_generation: evidence synthesis, reporting, next-round suggestions

Up in 5 Minutes

One-command Docker start; replay mode needs no API keys at all

git clone https://github.com/pdl-openair/OpenAIR.git
cd OpenAIR && cp .env.example .env
docker compose up -d --build
# Workbench: http://localhost:8080 · API: http://localhost:8000/health
