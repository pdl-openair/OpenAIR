## 1. 研究定位与差异化

### 1.1 问题重新定义

**v2 的问题定义**："哪个 OPE 方法最好？" → 已被 AutoOPE (2024) 通过监督学习方法回答。

**v3 的问题定义**："在 RL 训练过程中，OPE 方法的可靠性如何随策略演化而变化？我们能从可观测信号中预测何时应该切换方法吗？"

这一重新定义有三个优势：
1. **与 AutoOPE 互补而非竞争**：AutoOPE 学习一个黑盒选择器；我们提供可解释的决策规则和理论解释
2. **训练过程视角是独特贡献**：现有所有 OPE 研究（COBS, SCOPE-RL, AutoOPE）都在静态策略快照上评估，无人系统研究训练动态中的 OPE 行为
3. **可证伪性更强**：预测具体的切换点和可观测指标阈值，而非仅报告事后排名

### 1.2 与最新工作的差异化

| 最新工作 | 年份 | 他们做了什么 | 我们的差异 |
|---------|------|------------|-----------|
| **AutoOPE** (Felicioni et al.) | 2024 | 监督学习自动选择 OPE 估计器 | 他们是黑盒选择；我们提供可解释规则 + 训练动态分析 |
| **Cross-Validated OPE** (Cief et al.) | AAAI 2024 | 交叉验证选择 OPE 估计器 | 他们关注静态选择协议；我们关注训练过程中的动态选择 |
| **Model Selection for OPE** (Liu et al.) | 2025 | LSTD-Tournament 等新选择算法 | 他们提出新算法；我们提供系统性实证基础 |
| **SharpeRatio@k** (Kiyohara et al.) | ICLR 2024 | OPE 风险-回报权衡基准指标 | 他们定义了新指标；我们提供该指标在训练过程中的行为分析 |
| **SCOPE-RL** (Kiyohara et al.) | 2023 | OPE + 离线 RL + OPS 工具库 | 他们是工具；我们是实证研究（但也提供开源工具） |
| **COBS** (Voloshin et al.) | NeurIPS 2021 | 首个系统 OPE 基准（9 个离散环境） | 他们发现"no single estimator dominates"；我们回答"为什么"以及"何时该切换" |

**核心差异化陈述（elevator pitch）**：

> COBS (2021) 发现"没有单一 OPE 方法在所有场景下最优"。AutoOPE (2024) 用黑盒模型学习自动选择。**我们的工作填补中间空白**：首次系统研究 OPE 方法在 RL 训练过程中的可靠性变化，建立可解释的决策规则，回答"在训练的什么阶段应该信任哪个 OPE 方法，以及如何从可观测信号判断何时切换"。

## 2. 理论框架

### 2.1 核心概念：策略距离空间

将 v2 中分散的"训练进度"和"时间窗口"统一为**策略距离** (Policy Divergence) 这一核心概念：

```
d(π_b, π_e) = KL(π_e || π_b) 或 D_{TV}(π_e, π_b)
```

所有假说都围绕策略距离展开，但聚焦不同方面：

```
┌──────────────────────────────────────────────────────────────┐
│              OPE 方法在训练动态中的可靠性                       │
│                                                              │
│  策略距离 d(π_b, π_e) ─── 核心自变量                          │
│       │                                                      │
│       ├──→ H1'': 距离变化时，方法排序是否系统变化？             │
│       │         (排序变化假说)                                  │
│       │                                                      │
│       ├──→ H2'': 能否从可观测信号预测最优方法？                │
│       │         (可预测性假说)                                  │
│       │                                                      │
│       └──→ H3'': 数据量如何调节距离效应？                      │
│                 (数据效率假说)                                  │
│                                                              │
│  实验条件：                                                   │
│  ├── 操控距离的方式：                                         │
│  │   条件 A（固定 π_b，变 π_e 训练进度）→ "目标策略演化"       │
│  │   条件 B（固定 π_e，变 π_b 训练进度）→ "行为策略时间窗口"   │
│  │   两种条件构成对同一假说的交叉验证                           │
│  │                                                          │
│  ├── 调节变量：动作空间类型（离散 vs 连续）                    │
│  ├── 控制变量：环境、算法、种子                                │
│  └── 共享指标：MSE / Rank Correlation / Regret@k             │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 变量定义表（修订版）

| 变量名 | 类型 | 操作化定义 | 测量方式 |
|--------|------|-----------|---------|
| 策略距离 | 核心自变量 | 行为策略与目标策略的分布差异 | KL 散度 KL(π_e \|\| π_b)，或训练步数差作为代理 |
| 距离操控方式 | 实验条件 | 通过变化 π_e 或 π_b 来操控策略距离 | 条件 A（变 π_e）/ 条件 B（变 π_b） |
| OPE 方法 | 自变量 | 使用的 OPE 估计器 | IS / PDIS / WIS / DM / DR / SN-DR / FQE（7 个） |
| 离线数据量 | 调节变量 | OPE 评估使用的轨迹数 | 100 / 500 / 1K / 5K / 10K |
| 动作空间类型 | 调节变量 | 离散 vs 连续 | Gymnasium action_space 类型 |
| 估计精度 | 因变量 | OPE 估计与真实值的偏差 | MSE, Bias, Variance |

| 算法 | 控制变量 | SB3 算法 | DQN, PPO, SAC |

## 3. 可验证假说（重构版）

### H1''：OPE 方法排序随策略距离系统性变化（排序变化假说）

**陈述**：随着行为策略与目标策略的距离增大，OPE 方法的相对精度排序发生系统性变化——存在可量化的策略距离阈值，在该阈值前后，最优方法族从 IS 族切换到 DM 族。

**与 v2 的关系**：合并 H2'（训练进度）和 H3'（时间窗口）。两者本质上是操控同一变量（策略距离）的两种实验条件。条件 A（变目标策略）和条件 B（变行为策略）作为对同一假说的交叉验证。

**变量定义**：
- 核心自变量：策略距离 d(π_b, π_e)
  - 连续度量：KL 散度
  - 离散度量：训练步数差（代理变量）
  - 操控方式：条件 A（固定 π_b=ckpt_50%，变 π_e 从 10%→100%）+ 条件 B（固定 π_e=ckpt_80%，变 π_b 从 10%→80%）
- 自变量：OPE 方法（7 个水平）
- 因变量：MSE, Rank Correlation
- 调节变量：动作空间类型（离散 vs 连续）

**验证方法**：
1. 在条件 A 和条件 B 下分别运行所有 7 种 OPE 方法
2. 绘制 MSE 随策略距离的变化曲线（7 条线 × 2 条件）
3. 使用 Friedman + Nemenyi 后检验确定各距离区间的最优方法
4. 通过变点检测（PELT 或 Binary Segmentation）识别排序切换点
5. **关键检验**：条件 A 和条件 B 是否给出一致的切换阈值（交叉验证）
6. 使用 Spearman 相关量化"距离越远 IS 越差"的效应量

**预期结果**：
- 存在策略距离阈值 d*，使得 d < d* 时 IS/WIS 最优，d > d* 时 DM/FQE 最优
- 条件 A 和条件 B 给出一致的 d*（交叉验证成功）
- d* 的值受动作空间类型调节（离散环境的 d* > 连续环境）

**可证伪性条件**：
- 如果 Friedman 检验在所有距离水平下方法排序无显著变化（p > 0.05），则假说被证伪
- 如果条件 A 和条件 B 给出矛盾的结论，则需要重新审视策略距离的定义

**理论依据**：
- IS 估计量的方差 Var(V̂_IS) ∝ E[w²]，而 E[w²] 随 KL(π_e || π_b) 指数增长 (Precup, 2000; Thomas, 2015)
- DM 的偏差取决于 Q 函数拟合质量，与策略距离无直接关系 (Uehara et al., 2022)
- COBS (Voloshin, 2021) 发现"no single estimator dominates"但未解释何时切换

### H2''：最优 OPE 方法可从可观测信号预测（可预测性假说）——核心新颖贡献

**陈述**：存在可从离线数据和策略参数中直接获取的可观测信号（如策略熵 H(π_e)、IS 权重方差 σ²(w)、Q 值分布特征），能够预测当前条件下最优 OPE 方法，无需依赖对 ground truth 的先验知识。

**与 v2 的关系**：全新假说。v2 的"实践指南"是事后报告式的（"我们实验发现 XX 条件下 YY 方法最好"），H2'' 将其提升为事前预测式的（"给定这些可观测指标，你应该用 YY 方法"）。

**变量定义**：
- 自变量（预测特征）：
  - 策略熵 H(π_e) = -Σ π_e(a|s) log π_e(a|s)
  - IS 权重统计量：E[w], Var(w), max(w), P(w > 10)
  - Q 值分布：mean(Q), std(Q), |Q_max - Q_min|
  - 策略距离代理：d_step = |t_πe - t_πb| / T_total
- 因变量（预测目标）：最优 OPE 方法（7 分类）或 MSE 排名
- 评估方式：留一环境交叉验证（train on 3 envs, test on 1）

**验证方法**：
1. 从 RQ1 实验数据中提取每个 (条件, 距离, 方法) 组合的可观测特征
2. 训练简单分类器（逻辑回归 / 决策树）预测最优方法
3. 使用留一环境交叉验证评估泛化能力
4. 分析决策树规则，提取可解释的决策规则
5. 将提取的规则与理论预测（基于 IS 方差分析）进行对比

**预期结果**：
- 策略熵和 IS 权重方差是预测最优方法的最强特征
- 决策树提取的规则与 IS 方差理论一致："当 Var(w) > θ 时，切换到 DM/FQE"
- 留一环境验证准确率 > 70%（显著高于随机基线的 14%）

**可证伪性条件**：
- 如果所有分类器的留一环境验证准确率 ≤ 30%（接近随机），则假说被证伪
- 如果可观测特征无法区分 IS-最优和 DM-最优场景，则假说被证伪

**理论依据**：
- IS 方差 Var(V̂_IS) 与重要性权重的二阶矩 E[w²] 成正比，而 E[w²] 可从数据中估计
- 策略熵 H(π_e) 与策略确定性相关，确定性策略的 IS 权重方差更大
- AutoOPE (2024) 证明监督学习方法可以选择 OPE 估计器，但使用的是仿真数据标签，我们的可观测信号方法更实用

**与 AutoOPE 的差异化**：
- AutoOPE 需要在新环境中重新收集标签数据训练选择器；我们的规则是无需额外数据即可应用的
- AutoOPE 是黑盒模型；我们的规则是可解释的（决策树 / 阈值规则）
- AutoOPE 在静态策略上评估；我们在训练动态中评估

### H3''：数据效率的策略距离依赖性（数据效率假说）

**陈述**：OPE 方法的数据效率（达到给定精度所需的最少数据量）依赖于策略距离——距离越大，IS 族方法需要的额外数据量越多，而 DM/FQE 的数据需求对策略距离较不敏感。

**与 v2 的关系**：继承 H4'（数据量需求），但强调与策略距离的交互效应（v2 中 H4' 未考虑策略距离）。

**变量定义**：
- 自变量 X1：策略距离 d(π_b, π_e)（近/中/远三个水平）
- 自变量 X2：离线数据量（100 / 500 / 1K / 5K / 10K）
- 自变量 X3：OPE 方法（7 个）
- 因变量 Y1：MSE
- 因变量 Y2：达到 MSE < ε · V²_true 所需的最少数据量 N_min(ε, d, method)

**验证方法**：
1. 选择 3 个策略距离水平（近：d < d*/2, 中：d ≈ d*, 远：d > 2d*，其中 d* 来自 H1''）
2. 在每个距离水平下，从大数据集中随机抽取 5 个规模的子集
3. 对每个 (距离, 数据量, 方法) 计算 MSE
4. 拟合二维模型 MSE ≈ f(d, n)，分析距离×数据量的交互效应
5. 绘制 (策略距离, 数据量) 平面上的精度等高线图
6. 对每种方法，报告 N_min 随策略距离的变化率

**预期结果**：
- IS 族：N_min 随策略距离指数增长（因为 Var(w) 指数增长）
- DM/FQE：N_min 随策略距离缓慢增长（受 Q 函数外推误差影响，但不依赖权重）
- 存在"数据-距离等效"关系：增加数据量可以部分补偿策略距离的负面影响

**可证伪性条件**：
- 如果 ANOVA 显示策略距离×数据量的交互效应不显著（p > 0.05），则假说被证伪
- 如果所有方法的 N_min 对策略距离都不敏感，则假说被证伪

## 4. 实验设计（修订版）

**扩展环境（2 个，时间允许时加入）**：

| 环境 | 动作空间 | 状态×动作 | 时序长度 | 算法 | 选择理由 |
|------|---------|----------|---------|------|---------|
| Acrobot-v1 | 离散(3) | 6×3 | 500 | DQN, PPO | 离散环境鲁棒性验证 |
| Walker2d-v5 | 连续(6) | 17×6 | 1000 | SAC | MuJoCo 鲁棒性验证 |

### 4.2 连续空间 OPE 处理方案

**v2 的问题**：使用 KDE 近似连续策略密度，IS 权重爆炸至 3.8e+12。

**v3 的解决方案**：

| 方法 | 连续空间处理 | 理由 |
|------|------------|------|
| IS / PDIS / WIS | **仅使用 SAC 的参数化高斯密度**（不使用 KDE） | SAC 策略是 Gaussian(μ, σ)，可直接评估 log π(a\|s) |
| IS / PDIS / WIS | **对 PPO/TD3 策略使用正常流（Normalizing Flow）或放弃** | PPO 策略无解析密度；若实现困难，连续空间只报告 DM/FQE/DR |
| DM / FQE / DR / SN-DR | **不依赖策略密度** | 仅需 Q 函数，不受连续空间影响 |

**连续空间结果呈现策略**：
- 主论文中报告所有 7 种方法在所有环境上的结果
- 对连续空间 IS 族结果明确标注"KDE 密度估计限制"
- 在讨论部分分析连续空间 IS 失败的根因，作为有价值的发现

### 4.3 实验流程

```
阶段 1：策略训练 + 数据收集（同 v2）
├── 30 个训练任务 × 10 checkpoint × 10K 轨迹
├── Ground truth：复用 10K on-policy 轨迹均值

├── RQ1 实验（H1''：排序变化）
│   ├── 条件 A：固定 π_b=50%, 变 π_e={10%..100%}

│

```
