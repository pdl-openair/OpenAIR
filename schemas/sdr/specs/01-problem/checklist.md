# Checklist: Problem

## Review Checklist

### research-question.md

- [ ] Research questions are specific and researchable (not vague statements)
- [ ] Each question has a Q- ID assigned
- [ ] Each question traces to a gap (G-xxx) from gap-analysis.md
- [ ] Each hypothesis is falsifiable with a stated criterion
- [ ] Each hypothesis has an H- ID and links to a Q- ID
- [ ] Scope and constraints are explicitly declared
- [ ] Expected contributions are stated

### literature-review.md

- [ ] Literature review covers major relevant areas
- [ ] Search strategy is documented (databases, keywords, date range)

### gap-analysis.md

- [ ] Gaps are identified with G- IDs
- [ ] Each gap has a confidence level (high / medium / low)
- [ ] Gap-to-question mapping is complete (G-xxx → Q-xxx)

### Stage-level

- [ ] Research questions and literature gaps are consistent
- [ ] Hypotheses align with identified research gaps

### Type-specific

**Type M (Method):**
- [ ] Performance-driven research questions are measurable
- [ ] Hypotheses specify expected performance improvement direction

**Type D (Discovery):**
- [ ] Research questions target understanding or mechanism
- [ ] Hypotheses are exploratory where appropriate

**Type C (Computational-tool):**
- [ ] Research questions target utility or efficiency
- [ ] Hypotheses specify quantitative improvement targets

**Type H (Hybrid):**
- [ ] Both M-type and D-type questions are present
- [ ] Primary track is identified
