# CS 论文复现｜执行方案获取

## 目标

从已经固定并可追溯的官方来源中，形成真实复现后半链最小充分的执行计划事实，让系统能够继续准备资源和环境、运行程序并提取结果。

## 输入

- 当前复现研究目标；
- `reference_metric_acquisition` 已固定的官方来源包；
- 已进入 ScientificState 的正式 `reference_metric_records`。

## 输出边界

输出只包含下游真实消费的计划事实：

- 需要固定的资源及用途；
- Python / 依赖 / 导入核验要求；
- 程序入口、参数、工作目录、超时和必要环境变量；
- 资源与执行参数之间的绑定计划；
- 结果来源与正式参考指标对应的提取请求；
- 来源事实、本次系统选择、运行后才能产生的事实和当前未知。

计划不能声称资源已固定、环境已准备、程序已运行或指标已测得。

## 可信边界

- 来源明确要求：必须有可逐字核验的正式来源引用；
- 来源未指定的纯执行细节：仅在不改变科研含义、比较口径、明显成本或风险时，由代码形成本次系统选择并显式标记；
- 资源身份、实验参数、比较对象等会影响科研结论的事实不得猜测；
- 运行后才会存在的 execution record path、workspace result SHA256 等记为 runtime pending，不伪装成 unknown 或已完成事实；
- 一项候选事实引用无效时只隔离该项，保留其他已经核验的计划事实。
