# 文献获取

## 用户要得到什么

根据已经确认的检索策略，从当前可用的真实学术来源获取候选文献，形成可追溯的候选文献库，供下一阶段进行科研筛选。

## 结果要求

- 保留本次检索实际返回的候选，不在本阶段按科研价值、关键词命中或引用数删减。
- 合并重复文献并保留全部来源关系。
- 保留标题、来源、DOI、原始链接等可追溯信息。
- 整理后续可访问状态。
- 单个来源或单个检索请求失败时，保留其他已经取得的结果。
- 对失败来源、失败检索请求和运行上限造成的覆盖限制如实记录。

## 执行要求

- 执行上游提供的全部可执行检索式，不在本 Skill 内私自固定只取前 N 个。
- 多来源检索采用有界并行。
- 超时、并发数和候选容量属于运行保护，不代表科研完成标准。
- 去重、来源合并和访问状态整理使用确定性代码。
- 最终结果通过冻结 Schema 检查。
- 当前阶段不生成文献筛选、证据判断或科研结论。
