# 核心页面范围（简表）

OpenAIR 规划 **4** 个核心页面；实现优先级与前端当前落点如下。

| 页面     | 优先级 | 路由/入口（当前骨架）               | 说明                                         |
| -------- | ------ | ----------------------------------- | -------------------------------------------- |
| 主工作台 | P0     | `/` → `WorkbenchPage`（默认首页）   | 自然语言入口、人机协同、阶段结果、确认与修改 |
| 任务看板 | P0     | `/workbench` → `TaskBoardPage`      | 列表、阶段状态、进度、待办                   |
| 任务详情 | P1     | `/tasks/:taskId` → `TaskDetailPage` | 全过程、产物、能力调用、失败与回看           |
| 态势看板 | P2     | 未实现                              | 效能、统计、协作、Skill 使用                 |

主工作台为用户默认着陆页（`/`），是自然语言驱动科研任务的核心入口。

**目标目录命名**（与 `apps/web/src/pages/README.md` 一致）：`Workbench/`、`TaskBoard/`、`TaskDetail/`、`SituationBoard/`。不强制立刻物理搬迁为子目录。

通用平台：**不要**在页面或路由层写死单一材料或单一学科为唯一主场景。
