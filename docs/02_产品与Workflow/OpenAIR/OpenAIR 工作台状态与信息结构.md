# OpenAIR 工作台状态与信息结构

> 状态：已确认  
> 更新时间：2026-10-08  
> 职责：规定工作台面向用户的状态空间、三栏壳、模块组合与关键交互。

---

## 1. 工作台

用户进入一项研究后，始终使用同一套工作台。不同处境只改变各栏投影，不更换布局，不为单态定制整页。

```text
┌──────────────┬─────────────────────────┬──────────────────────────────┐
│ 左·四阶段     │ 中·产物区                │ 右·协作区                     │
│              │                         │  过程说明、对话、情境信息块      │
│ 问题建模      │  当前可查看的研究产物      │                              │
│ 方案设计      │                         │  ┌──────────────────────────┐ │
│ 执行验证      │                         │  │ 底栏                      │ │
│ 结果总结      │                         │  │ [空|重试|继续]     [输入→] │ │
│              │                         │  └──────────────────────────┘ │
└──────────────┴─────────────────────────┴──────────────────────────────┘
```

进入工作台后，输入框始终存在，并连接同一研究助手。

中栏只放产物。研究过程、耗时、说明与推进动作放在协作区。不得把进展画进中栏。

---

## 2. 四阶段

左栏固定四级，名称如下：

| 顺序 | 阶段 |
| --- | --- |
| 1 | 问题建模 |
| 2 | 方案设计 |
| 3 | 执行验证 |
| 4 | 结果总结 |

研究方案尚未产出时，四级全部展示，呈未开始/淡显。方案确认后按方案点亮并推进；失败标在当前相关阶段。

---

## 3. 用户状态

工作台面向用户的合法状态只有下列 9 种。

| 状态 | 用户含义 | 主操作 |
| --- | --- | --- |
| 方案生成中 | 研究方案还在准备。卡住时仍属本态：说明正在再核对同一项研究，可再检查；不升格为独立状态，不默认另起一次 | 等待或再检查 |
| 方案生成失败 | 研究方案这次没有形成；研究仍在本工作台 | 重试 |
| 方案待确认 | 方案草案已形成，等待确认 | 确认 / 修改 |
| 方案已确认 | 方案已确认，研究尚未开始执行 | 开始研究 |
| 执行中 | 按已确认方案推进 | 必要时停止 |
| 待处理 | 执行停在需要用户处理的节点 | 确认，或补充后继续 |
| 执行失败 | 这次执行没有做成；已有产物保留 | 重试 |
| 执行完成 | 研究已完成 | 查看产物与结论 |
| 执行停止 | 研究被停下，不是做成 | 继续（若允许） |

方案生成失败与执行失败对用户是同一类反应：协作区说明失败，底栏给出「重试」。重试作用在当前失败对象上：方案未形成则按用户一开始选定的方式，在同一项研究上重新生成方案；执行失败则重做该次执行。不得要求用户「先完成方案才能重试」。

方案生成中若一次生成尚未核对清楚，协作区说明正在再核对同一项研究，主操作是再检查，不是重试。

## 4. 模块

各栏只使用下列投影值。状态 = 这些值的组合。

| 模块 | 取值 |
| --- | --- |
| 左·阶段 | 未产出淡显 · 按方案推进 · 失败标 |
| 中·产物 | 暂无产物 · 方案草案/已确认方案 · 执行产物 · 结束产物 |
| 右·协作流 | 形成中说明（含再核对）· 失败说明 · 过程对话 · 情境信息块 |
| 底栏左 | 空 · 重试 · 继续 |
| 底栏右 | 输入 + 发送 |

### 组合

| 状态 | 左 | 中 | 右 | 底栏左 |
| --- | --- | --- | --- | --- |
| 方案生成中 | 淡显 | 暂无产物 | 形成中说明；卡住则再核对/再检查 | 空 |
| 方案生成失败 | 淡显 | 暂无产物 | 失败说明 | 重试 |
| 方案待确认 | 淡显 | 方案草案 | 信息块：确认、修改 | 空 |
| 方案已确认 | 按方案点亮 | 已确认方案 | 信息块：开始研究 | 空 |
| 执行中 | 推进中 | 已有产物 | 过程流；信息块：停止 | 空 |
| 待处理 | 停在卡点 | 已有产物 | 阻塞信息块：确认或补充 | 空 |
| 执行失败 | 相关阶段失败标 | 产物保留 | 失败说明 | 重试 |
| 执行完成 | 收束 | 结果产物 | 可继续询问 | 空 |
| 执行停止 | 停点 | 产物保留 | 已停止说明 | 继续（若允许） |

---

## 5. 交互

| 动作 | 出现位置 | 行为 |
| --- | --- | --- |
| 发送 | 底栏右，固定 | 把输入交给研究助手 |
| 重试 | 底栏左，失败时 | 对当前失败对象发起下一次；方案失败与执行失败同一入口 |
| 继续 | 底栏左，停止且允许时 | 从停止点恢复研究 |
| 停止 | 协作区信息块，执行中按需出现 | 停下当前研究 |
| 确认 | 协作区信息块，按需出现 | 点即生效 |
| 补充 | 协作区信息块，出现阻塞时 | 点后聚焦输入框；用户写完再发送。不是底栏固定按钮 |
| 开始研究 | 协作区信息块，方案已确认时 | 点即开始执行 |
| 修改研究方案 | 协作区信息块，方案待确认时 | 进入方案修改 |

确认 ≠ 补充。确认不跳到输入框。补充不直接提交。

底栏左同时只显示一个情境按钮，或为空。不得把暂停做成底栏左的常驻按钮。
