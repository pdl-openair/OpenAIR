# OpenAIR PVD MVP｜产品合同

> 状态：已确认
> 更新时间：2026-08-31
> 职责：定义 PVD MVP 向用户提供的产品能力、结果范围和验收要求。

## 1. 产品定位

PVD MVP 面向需要确定或持续优化 PVD 工艺条件的研究项目。

产品支持两类场景：

- 实验尚未开始时，根据研究目标、已有证据、材料和设备条件形成首轮工艺参数建议；
- 已有真实实验反馈时，结合真实执行和测量结果形成下一轮工艺参数建议。

用户可以持续提交新的真实实验信息，系统基于已经形成的项目事实继续研究。

系统不预先限定推荐参数的数量和种类。具体研究、推荐或持续优化哪些参数，由当前 ResearchTask、ResearchDesign、已确认实验事实、设备能力、用户约束和证据共同决定。

## 2. 产品范围

PVD 参数推荐能力不固定为某几个参数。

系统可以根据当前研究任务，对相关 PVD 工艺参数进行分析，并在证据、设备边界和实验条件允许时形成具体建议。

同一个工艺参数在不同项目中可以是：

- 需要推荐或优化的参数；
- 已固定的实验条件；
- 设备、安全或工艺约束；
- 结果解释所依赖的科研事实。

参数扮演什么角色，由当前研究任务决定，不由系统预先写死。

### 2.1 当前演示案例

当前 AlN / AlSc 演示案例选择以下四个参数作为主要推荐和优化变量：

| 参数 | 单位 |
|---|---|
| 功率 | W |
| N₂ 流量 | sccm |
| Ar 流量 | sccm |
| 沉积时间 | s |

N₂/Ar 比例、总流量和氮气占比可以根据 N₂、Ar 流量计算并展示。

这四个参数只是当前演示案例的选择，不是 PVD 产品能力的固定边界。温度、压力、偏压、退火条件、靶材、衬底、靶基距等，应根据具体研究任务判断其角色，不能因为当前案例没有将其纳入四参数，就默认禁止系统研究或推荐。

### 2.2 LLM 参数推荐与 BO 参数优化

LLM 参数推荐与贝叶斯优化（BO）的职责不同：

- LLM 可以结合研究目标、证据、已有实验、设备条件和用户约束，分析并推荐当前任务需要的工艺参数，不预先限制参数数量和种类；
- BO 只处理满足其建模和优化条件的参数子集；
- 不满足 BO 条件的参数，不得为了进入 BO 而被强行数值化、补默认值或改写事实；
- 未进入 BO 的参数，仍可由 LLM 基于证据和真实实验反馈继续分析、推荐和调整；
- BO 只决定哪些参数进入数值优化，不决定 PVD 系统可以推荐哪些参数。

## 3. 信息不完整时的产品行为

设备和实验信息不完整时，只要已有事实足以支持当前建议，产品可以继续，并明确显示重要未知条件、假设和风险。

如果缺失信息已经影响实验安全、硬约束，或导致系统无法形成合法可执行的建议，则必须停止当前建议并要求补充必要事实。

产品不得用默认值、模型猜测或历史值，把未知科研事实伪装成已知事实。

## 4. 用户获得的结果

### 4.1 首轮建议

实验尚未开始时，用户至少能够看到：

| 内容 | 要求 |
|---|---|
| 推荐参数 | 展示当前研究任务实际需要推荐的参数；给出具体值或范围，并在适用时标明单位 |
| 参数依据 | 分别说明每个推荐参数为什么这样设置 |
| 参数角色 | 区分待推荐/优化参数、固定条件、约束和其他科研事实 |
| 关键条件 | 当前建议依赖的主要材料、设备和实验条件 |
| 未确认信息 | 当前仍缺少或尚未确认的重要条件 |
| 实验要求 | 本轮需要保持、测量或记录的必要内容 |
| BO 状态 | 如使用 BO，说明哪些参数进入 BO、哪些未进入，以及原因 |

首轮不要求一次找到最优工艺。

当前 AlN / AlSc 演示案例中，首轮正式推荐参数为功率、N₂ 流量、Ar 流量和沉积时间。

### 4.2 后续轮次建议

用户完成实验并提交真实执行和测量结果后，产品形成下一轮建议。

对于当前研究任务中的每个正式推荐参数，需要能够展示：

| 参数 | 本轮实际 | 下一轮建议 | 调整方向 | 主要依据 |
|---|---|---|---|---|
| 当前参数 | 实际执行值 | 具体值、范围或保持条件 | 提高 / 降低 / 保持 / 其他适用变化 | 本轮实验、相关证据与当前约束 |

参数保持不变时，也需要说明原因。

如果部分参数进入 BO，应同时保留 BO 的数值优化结果及其适用边界。未进入 BO 的参数仍可由 LLM 基于证据和真实实验反馈形成下一轮建议。

## 5. 用户可理解的事实区分

产品必须让用户清楚区分：

```text
系统正式建议
≠ 用户正式确认的计划
≠ 实际执行
≠ 真实测量结果
```

系统给出建议后，用户可以在真实实验前确认或修改计划。

实际执行与计划不同属于合法科研事实，不能反向改写原建议或原计划。

文献等外部资料中的实验结果，也必须与当前项目的真实实验结果明确区分。

具体科研事实如何长期保存，由《PVD 科研状态事实合同》定义。

## 6. 产品验收要求

| 验收项 | 要求 |
|---|---|
| 参数范围 | 参数推荐能力不预先限定参数数量和种类；实际参数集合由当前研究任务和科研事实决定 |
| 演示案例 | 当前 AlN / AlSc 演示案例能够形成针对功率、N₂ 流量、Ar 流量和沉积时间的完整建议 |
| 首轮建议 | 已有信息足够时，可以针对当前任务所需参数形成首轮建议 |
| 参数依据 | 每个正式推荐参数都有具体、可理解、可追溯的依据 |
| 参数角色 | 能够区分待推荐/优化参数、固定实验条件、约束和其他科研事实 |
| BO 边界 | 只有满足 BO 条件的参数进入 BO；BO 不得限制 LLM 可研究或推荐的参数范围 |
| 已知条件 | 已确认的设备、安全和实验条件进入判断 |
| 未确认信息 | 影响建议的重要未知条件明确显示 |
| 用户计划 | 用户可以在实验前确认或修改计划，且不覆盖原系统建议 |
| 事实区分 | 建议、计划、实际执行和真实测量能够被明确区分 |
| 后续建议 | 获得有效真实实验反馈后，可以针对当前任务参数形成下一轮建议 |
| 轮次对比 | 后续建议能够展示本轮实际、下一轮建议和调整方向 |
| 多轮连续性 | 后续研究能够读取已经形成的正式项目事实继续推进 |
