# 可复现研究包（Research Package）

> 状态：v0.3 定稿  
> 日期：2026-09-28

Research Package 把一项已经完成、来源可追溯的研究整理成下一位科研人员可以直接理解和复用的研究起点。

这里的“可复现”不表示每次使用都必须先重跑原研究。Package 应保留足够的方法、参考实例、资源身份和适用边界，使新项目能够判断哪些内容可以直接参考、哪些需要重新核验，以及条件变化会怎样影响可信度。文中的“已验证参考实例”只表示原研究实际完成过的验证及其边界，不等同于统一认证或默认已经独立复现。
