# Dev: Onboarding

## When to use

新开发者需要了解项目结构、开发流程和关键文档入口。

## Rules source

Read for orientation:

- `docs/03_工程/待专项更新/GETTING_STARTED.md` -- role-based reading paths, first-day checklist
- `docs/03_工程/工程架构/OpenAIR_Architecture-Code_Map.md` -- directory tree, code placement rules
- `CONTRIBUTING.md` -- contribution guidelines and document index

## Output

Role-based orientation: point the developer to the right docs based on their role (frontend, backend, skill dev, AI coding user, reviewer).
