# OpenAIR 研究资料整理规范

> 状态：已确认  
> 更新时间：2026-09-20  
> 职责：规定论文、实验记录等原始研究资料怎样被忠实整理，并保持研究对象、条件、结果及来源之间的可追溯关系。

---

## 1. 核心合同

研究资料整理首先保留**原始资料实际报告了什么，以及这些内容在什么上下文中成立**。

每项提取结果至少必须同时保留以下四类信息，原资料未提供的内容则保留其真实缺失状态：

```text
研究对象
+ 相关条件
+ 原资料报告的结果
+ 来源位置
```

当结果的含义依赖单位、指标定义或测量 / 评价方法时，这些信息或其真实缺失状态也必须一起保留。

例如，只记录“d33 = 10 pC/N”不足以支持后续使用。整理结果还需要保留它对应的材料或样品、相关实验条件、指标或测量方法，以及原资料中的具体来源位置。

整理过程不能为了便于比较、分析或下游使用，改变原资料中的对象关系、结果含义或来源身份。

---

## 2. 保持原资料中的对应关系

一份资料可能包含多个样品、多次实验、多组条件和多个结果。整理时必须保持原资料中的对应关系。

不同样品、实验组或运行结果不能被合并成原资料中不存在的“综合结果”。

同一个样品或同一次实验可以对应多个结果，例如成分、膜厚、应力、取向和 d33。这些结果可以共享同一个研究对象或实验条件，但每个结果自己的定义、测量方法和来源位置仍应分别保留。

只有原资料本身报告了汇总、平均或其他聚合结果时，才能把该聚合结果作为原资料报告的内容记录；整理过程不能自行生成新的聚合结果并写成来源事实。

---

## 3. 每项结果需要保留的信息

每项整理结果应能够表达以下信息。原资料没有提供、当前无法取得或不适用时，按第 5 节保留对应状态，不得补造。

| 信息 | 需要保留的内容 |
| --- | --- |
| **研究对象** | 该结果对应的材料、样品、模型、实验对象或其他研究对象 |
| **条件** | 得到该结果时适用的实验、运行或研究条件 |
| **结果** | 原资料实际报告的数值、现象、观察或运行结果 |
| **单位和定义** | 数值单位，以及理解该指标所必需的定义 |
| **测量或评价方法** | 结果如何测量、计算或评价；其差异会影响结果含义时必须保留 |
| **来源位置** | 原资料身份，以及能够回到该内容的表格、图片、段落、页码或实验记录位置 |
| **误差和限制** | 原资料明确报告的误差、不确定性或适用限制 |

结果不一定是数值。“样品出现裂纹”“没有检测到目标晶相”“模型运行失败”等，只要是原资料实际报告的内容，都可以作为结果记录。

所有整理结果都必须能够追溯到其原始来源。

---

## 4. 区分来源内容与后续处理

同一研究过程中可能同时出现原始记录、论文直接结果、作者解释、确定性处理结果和 OpenAIR 的科研判断。这些内容可以关联，但不能混成同一种来源事实。

| 内容 | 应保留的身份 |
| --- | --- |
| 用户记录“实际用了 220 W” | 用户提供的实际记录 |
| 论文报告“d33 = 10 pC/N” | 论文直接报告的结果 |
| 作者认为“性能提升可能与取向改善有关” | 作者解释 |
| 将原资料中的 0.5 min 换算为 30 s | 基于原值形成的确定性换算结果，并保留原值来源 |
| OpenAIR 判断“这篇论文只能作为方向参考” | OpenAIR 形成的科研判断 |

必须保持以下关系：

- 后续建议或分析不能覆盖原资料实际报告的值；
- 确定性换算或派生结果必须与原始值区分，并能够追溯回原始值；
- 作者解释不能写成原资料直接观察到的实验事实；
- OpenAIR 的科研判断不能写成原资料自身的结论。

---

## 5. 缺失、不明确与不适用

资料中的空缺需要保留真实原因，不能统一写成一个模糊的“缺失”。

| 情况 | 记录语义 |
| --- | --- |
| **原资料没有报告** | 该资料中未报告这项信息 |
| **当前无法获取** | 信息可能存在，但当前无法取得对应内容 |
| **含义无法确认** | 已取得相关内容，但当前无法确定其准确含义 |
| **不适用** | 该项信息对当前对象或结果本身不适用 |

这些状态不能互相替代。

资料不完整时，不得为了满足结构、方便比较或继续分析而补造值、条件、单位、方法或其他来源事实。

---

## 6. 整理内容与 Evidence

整理后的资料内容首先保持为**对原始来源的忠实记录**。

```text
已整理的来源内容
≠
Evidence
```

当某项具体内容被确定为能够支持、反驳或限制某个科研判断，并建立了该内容与相应科研判断之间的证据关系时，才形成 **Evidence**。

```text
原始资料
→ 忠实整理并保留来源关系
→ 确定与具体科研判断的关系
→ 形成 Evidence
```

Evidence 继续保留其原始来源、适用条件和相关不确定性；形成 Evidence 不会改变原资料本身报告的内容。
