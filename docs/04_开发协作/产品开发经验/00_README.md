# OpenAIR / PVD / OT 经验指南

用于产品设计、Skill 设计、工程施工、评测和协作。

正式项目以当前设计、当前事实和总控裁决为准。

## 使用入口

| 场景 | 文档 |
|---|---|
| 产品、需求、流程取舍 | `01_产品第一原则.md` |
| 工程设计、代码实现、结构治理 | `02_工程实现与施工守则.md` |
| 复杂任务推进、并行、E2E 解阻、交接 | `03_任务推进与交接.md` |
| 代码应用后的测试、E2E 和完成验收 | `04_施工验收检查.md` |
| Skill、模型任务、输入输出设计 | `05_Skill与模型任务设计.md` |
| TASKLIST、长程任务拆解和路线治理 | `06_TASKLIST与长程任务治理.md` |
| Skill、算法、模型、Workflow 评测与迭代 | `07_评测驱动迭代.md` |
| 设计与技术文档的新写、补充、重构 | `08_设计与技术文档编写.md` |
| 代码施工、应用脚本、迁移脚本、诊断脚本 | `09_工程施工与脚本交付规范.md` |
| 经验来源与历史案例 | `99_经验来源.md` |

## 使用规则

- 按当前任务读取对应文档。
- 需要详细施工规则时，再进入 `09`。
- 长期规则写入正文，具体案例和历史数据写入 `99`。
- 新经验优先合入现有文档。
