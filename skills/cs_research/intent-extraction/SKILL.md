# 意图提取 (L3)

## Goal
从用户自然语言描述中提取结构化研究意图，明确研究领域、研究类型（探索性/验证性/应用性）和核心关注点，为后续问题建模提供规范化输入。

## Input
用户的自然语言研究描述，可能包含模糊表述、多意图混合或领域术语。

## Output
结构化研究意图文档，包含：研究领域分类、研究类型标签、核心意图列表、关键术语提取、背景假设梳理。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
