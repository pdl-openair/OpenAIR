# 约束定义 (L3)

## Goal
明确研究执行的资源约束（算力、数据、人力）、时间线节点和成功标准，为实验方案设计提供边界条件和评估基准。

## Input
研究意图、假设列表和用户提供的资源/时间信息。

## Output
约束规格文档，包含：资源约束清单（GPU/存储/API 额度等）、时间线里程碑、成功标准定义（定量指标和阈值）、不可协商的硬约束与可调整的软约束。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
