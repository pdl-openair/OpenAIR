# 报告撰写 (L3)

## Goal
基于论点蓝图和全部实验证据，撰写完整的研究报告或学术论文草稿，包含摘要、引言、方法、结果、讨论和结论各部分，并生成配套图表。

## Input
论点蓝图、发现整合报告、质量审计报告和原始实验数据。

## Output
研究报告/论文草稿（Markdown 或 LaTeX 格式），包含：摘要、引言（含文献定位）、方法（可复现细节）、结果（含图表）、讨论（含局限性和未来工作）、结论、参考文献。附：图表文件和数据可视化脚本。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
