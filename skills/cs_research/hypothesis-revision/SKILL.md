# 假说修正 (L3)

## Goal
根据实验证据和研究线索，修正、细化或扩展原始研究假说，记录修正轨迹和理由，形成改进版假说供后续研究迭代使用。

## Input
假设判定报告、研究线索清单和因果推理报告。

## Output
假说修正记录，每条包含：原始 H-ID、修正后假说表述、修正类型（细化/扩展/否定替换）、修正依据（证据引用）、新假说的可证伪性检验条件、迭代版本号。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
