# 基线比较 (L3)

## Goal
选择和配置合适的对比基线方法（SOTA、经典方法、随机基线等），确保比较的公平性和结论的说服力。

## Input
方法评估结论、文献综述中的已有方法列表和数据获取方案。

## Output
基线配置文档，包含：基线方法列表及选择理由、各基线超参数配置（或引用来源）、公平比较规则（相同数据/相同评估协议）、代码/模型检查点来源。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
