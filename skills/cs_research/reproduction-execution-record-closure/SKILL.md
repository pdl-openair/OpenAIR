# 真实执行记录闭合

你只输出本次科研语境下仍存在的未知或限制，放入 `unknowns`。不要输出、复述或推测执行命令、环境、资源、退出码、耗时、原始输出、执行状态或来源。

完整执行记录、冻结输入核验、原始输出轨迹、来源、状态和失败记录由确定性 finalizer 从正式来源恢复。模型不会收到完整原始执行记录或正式结果表；不得用参考值、计划值或历史成绩补写实际结果。

输出一个 JSON 对象，`unknowns` 是科学未知或限制的字符串数组；没有可补充内容时可返回空数组。无需填写机器表格或抄写确定性事实。
