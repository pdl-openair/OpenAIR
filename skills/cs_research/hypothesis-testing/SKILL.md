# 假设检验 (L3)

## Goal
将统计检验结果和结构化证据映射回研究假设，对每个假设做出明确的判定结论（支持/不支持/部分支持），量化证据强度。

## Input
统计检验报告、结构化证据表和原始假设列表。

## Output
假设判定报告，每条假设包含：H-ID、判定结论、支持证据 ID 列表、证据强度评级（强/中/弱）、与预期一致程度、意外发现说明。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
