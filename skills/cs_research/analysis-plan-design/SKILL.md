# 分析方案设计 (L3)

## Goal
在实验执行前预注册分析方法和统计检验计划，明确首要分析与次要分析、多重比较校正策略，防止 p-hacking 和选择性报告。

## Input
假设列表、变量规格表和选定方法的预期输出特性。

## Output
预注册分析方案，包含：首要分析方法、统计检验选择及理由、显著性水平设定、多重比较校正方法、效应量指标、次要分析计划、事态分析（contingency）预案。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
