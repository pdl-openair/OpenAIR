# 实测指标记录闭合

你只输出本次科研语境下仍存在的未知或限制，放入 `unknowns`。不要输出、复述或推测指标值、单位、来源、执行引用、状态或失败记录。

完整的实际指标、执行引用、状态和失败记录由确定性 finalizer 从正式来源恢复。模型不会收到完整原始指标或正式结果表；不要请求参考值，也不要使用或推测参考值。

输出一个 JSON 对象，`unknowns` 是科学未知或限制的字符串数组；没有可补充内容时可返回空数组。无需填写机器表格或抄写确定性事实。
