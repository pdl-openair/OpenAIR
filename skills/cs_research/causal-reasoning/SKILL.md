# 机制争议图谱 (L3)

## Goal
基于已有证据整理机制解释，回答“哪些机制边有证据、哪些只是推断、哪些解释相互冲突、下一轮验证缺什么”。输出必须保留证据追溯，而不是把机制故事写成确定结论。

## Input
需要已有证据基础：

- 证据表、证据节点、来源包或用户提供的论文/实验摘录。
- 候选机制假说、争议问题或需要比较的解释路线。
- 可选：实验条件、表征手段、对照组、指标变化、时间尺度。

只有主题、题录或摘要时，停止并返回缺输入清单。

## Procedure

1. **证据可用性检查**
   - 确认证据条目是否有 evidence_id 或 source_locator。
   - 标出仅有摘要、作者讨论或无法定位的材料。

2. **机制节点抽取**
   - 抽取对象、处理/变量、观察结果、中介机制、最终结果。
   - 每个节点写清材料来源和不确定性。

3. **机制边分级**
   - evidence_edge：有直接实验、表征、对照或定量结果支持。
   - inference_edge：合理推断但缺直接证据。
   - conflict_edge：不同来源或条件下给出相反解释。
   - gap_edge：关键环节缺证据。

4. **替代解释与验证缺口**
   - 列出至少一种替代解释或混杂因素。
   - 给出下一轮验证需要的对照、表征、时间尺度或数据。

## Output
输出机制争议图谱：

```markdown
| edge_id | from_node | to_node | edge_type | evidence_ids | rationale | uncertainty_or_gap |
|---|---|---|---|---|---|---|
```

并附：

- **机制链草图**
- **证据边/推断边/冲突边/gap 边清单**
- **替代解释**
- **下一轮验证建议**
- **人工复核优先级**

## Constraints
- 每条机制边必须引用 evidence_ids 或标为 inference/gap。
- 不能把相关性、共现、作者猜测写成确定因果。
- 条件不可比时必须标出实验条件、表征手段或样本差异。
- 缺证据时输出机制缺口，不输出确定机制结论。
