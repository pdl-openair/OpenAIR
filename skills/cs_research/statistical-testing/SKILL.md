# 统计检验 (L3)

## Goal
严格按照预注册分析方案执行统计检验，报告 p 值、置信区间和效应量，确保分析的透明性和可追溯性，杜绝选择性报告。

## Input
结构化证据表和预注册分析方案。

## Output
统计检验报告，包含：检验方法、原假设与备择假设、p 值、置信区间、效应量（Cohen's d / eta-squared 等）、多重比较校正结果、结论（拒绝/无法拒绝原假设）。

## Constraints
- 必须基于前序 substage 的 spec 产出
- 产出必须可追溯
