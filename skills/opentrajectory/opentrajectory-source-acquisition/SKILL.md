# 文献获取

## 用户得到什么

本 Skill 根据上游已经确认的检索策略，从当前启用的真实学术来源获取可追溯候选文献。

本阶段保留本次检索实际返回的候选，不判断哪篇文献更有科研价值，也不按关键词、引用数或固定科研分数提前淘汰候选。

## 执行方式

1. 执行上游提供的全部可执行检索式。
2. 并行访问 OpenAlex、Semantic Scholar、arXiv 等当前启用来源。
3. 单个来源或单个检索请求失败时，保留其他已经取得的结果。
4. 使用确定性代码合并重复文献和来源记录。
5. 使用确定性代码整理后续可访问状态。
6. 使用冻结 Schema 检查最终结果。

## 运行限制

- 单次外部请求存在超时保护。
- 多来源检索使用有界并行。
- 每次请求和整次候选池可以设置运行容量上限。
- 这些限制只用于控制运行时间和资源，不代表文献已经穷尽。
- 触发候选容量上限、来源失败或检索请求失败时，结果必须如实记录覆盖限制。

## 职责边界

### LLM

本 Skill 不负责科研筛选。文献相关性、优先级和证据价值由下一阶段的 LLM 筛选负责。

### 代码

代码负责：

- 外部检索调用；
- 文献身份去重；
- 来源关系合并；
- DOI / 链接等元数据整理；
- 访问状态整理；
- 运行限制和覆盖不足记录；
- Schema 校验。
