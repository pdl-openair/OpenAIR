# Contract Notes

- Formal substage: `hypothesis_update`.
- Claim layer: `unvalidated_falsifiable_hypothesis` only.
- `mechanism_packet` is optional because the frozen handoff contract permits `mechanism_explanation` to be skipped; findings and accepted research leads remain required.
- Inputs are accepted upstream research leads plus the evidence/findings/mechanism context needed to bound and trace the hypothesis.
- The model owns scientific interpretation and semantic judgments.
- Deterministic code owns schema, reference existence/containment, canonical identity, deduplication, limits, fingerprint, summary/audit, degraded state, and final schema validation.
- Evidence motivating a hypothesis never converts it into an established finding.
- Gap provenance may motivate a hypothesis but cannot establish the predicted effect.
