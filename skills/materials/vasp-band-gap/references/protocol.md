# MatterGen Band-Gap Protocol — Full INCAR Spec

Source: [microsoft/mattergen#213](https://github.com/microsoft/mattergen/issues/213)
(ClaudioZeni's reply), reproduced in
`scripts/compute_band_gap.py::build_band_structure_maker`.

The protocol is **DoubleRelax → PBE BandStructure**, where BandStructure
itself is **static → non-scf uniform → non-scf line**. All four makers
inherit from `MPRelaxSet.yaml` (pymatgen) with `Yb_2` POTCAR pinned for
cross-calculation consistency.

## Step 00 — MP-GGA Relax 1 (coarse)

`MPGGADoubleRelaxMaker` first maker. From `MPRelaxSet.yaml` defaults:

- ISIF = 3 (full cell + ionic relax)
- IBRION = 2 (CG)
- NSW = 100
- EDIFF = 1e-4
- EDIFFG = -0.02
- ISMEAR = 0, SIGMA = 0.05
- ENCUT = 520 (MP standard)
- PREC = Accurate
- ALGO = Normal
- LREAL = Auto (auto-recursive real-space projection)

## Step 01 — MP-GGA Relax 2 (fine)

`MPGGADoubleRelaxMaker` second maker. Same as above except:

- ISIF = 2 (only ionic positions, hold cell fixed from step 00)
- EDIFF = 1e-5 (tighter)
- Restarted from step 00's CONTCAR/WAVECAR

## Step 02 — Static SCF

`StaticMaker` with `StaticSetGenerator`, base `MPRelaxSet.yaml` + overrides:

```python
{
    "IBRION": -1,      # no ionic updates (single-point)
    "ISMEAR": -5,      # tetrahedron method with Blöchl corrections
    "LAECHG": True,    # write AECCAR0/1/2 (for Bader later if wanted)
    "LCHARG": True,    # write CHGCAR (consumed by non-scf)
    "LORBIT": 11,      # write PROCAR/PROCAR with f-orbital projection
    "LVHAR": True,     # write LOCPOT (for potential analysis)
    "LWAVE": False,    # don't write WAVECAR (saves disk)
    "NSW": 0,          # zero ionic steps
    "ALGO": "Normal",  # robust SCF for insulators/semiconductors
}
```

KPOINTS: `reciprocal_density = 100` → for MoS2 yields 9×9×2 Gamma mesh.

## Step 03 — Non-SCF Uniform (DOS)

`NonSCFMaker` with `NonSCFSetGenerator`, base `MPRelaxSet.yaml` + overrides:

```python
{
    "SIGMA": 0.001,
    "ISTART": 1,         # restart from static's WAVECAR
    "LASPH": False,      # explicit (slight speed-up)
    "NELMDL": 0,
    "APACO": 16,         # ⚠️ unusual flag — pair-correlation-related
    "GGA": "PE",
    "NATURALO": 0,
    "ALGO": "Normal",
    "ENCUT": 520,
    "KPOINT_BSE": [-1, 0, 0, 0],   # ⚠️ unusual flag — disables BSE post-processing
    "ICHARG": 11,        # (set by NonSCFSetGenerator) read CHGCAR, no SCF
}
```

KPOINTS: auto-generated uniform mesh at higher density than static.

⚠️ `APACO` and `KPOINT_BSE` are non-standard for a band-structure non-scf.
On at least one VASP build (the one on HPCSlurmArm), they appear to trigger
a runtime abort. See [`non-scf-debug.md`](non-scf-debug.md).

## Step 04 — Non-SCF Line (Band Structure)

Same maker + INCAR as step 03, only KPOINTS differs: line mode along the
high-symmetry path generated by `pymatgen.symmetry.bandstructure.KpathSetyawanCurtarolo`.

For MoS2 (hexagonal), the path is Γ–M–K–Γ–A–L–H–A, plus L–M, K–H segments.
Line density = 152 points (small system → dense line).

## Output Parsing

After step 04, `pymatgen.io.vasp.Vasprun.eigenvalue_band_properties` returns
a tuple `(gap, cbm, vbm, direct)` (all in eV; `direct` is bool).

If step 04 is unavailable (e.g., due to the cluster crash), the same tuple
can be extracted from step 02's vasprun.xml — but the gap is computed on
the uniform mesh rather than along the high-symmetry path. For typical
semiconductors without pathological band dispersion, the values agree to
within ~0.05 eV.
