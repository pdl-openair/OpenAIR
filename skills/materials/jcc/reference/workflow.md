# 典型工作流列表

## 概述

本文件列出jcc cli可以执行的典型工作流。

## 工作流列表

### 1. 数据处理工作流 (data-processing)

**描述**: 上传数据 -> 调度到算力中心 -> 执行计算任务 -> 下载结果

**涉及步骤**:
- 数据上传
- 数据调度
- 超算任务提交
- 结果下载

**参考文档**: workflow/data-processing.md

---

### 2. AI模型训练工作流 (ai-training)

**描述**: 上传训练数据 -> 提交智算训练任务 -> 监控训练进度 -> 获取模型

**涉及步骤**:
- 数据上传
- 智算任务提交（训练）
- 任务状态查询
- 模型下载

**参考文档**: workflow/ai-training.md

---

### 3. AI模型推理工作流 (ai-inference)

**描述**: 上传输入数据 -> 提交智算推理任务 -> 获取推理结果

**涉及步骤**:
- 数据上传
- 智算任务提交（推理）
- 结果下载

**参考文档**: workflow/ai-inference.md

---

### 4. 虚拟机部署工作流 (vm-deployment)

**描述**: 创建虚拟机 -> 配置虚拟机 -> 部署应用

**涉及步骤**:
- 通算任务提交（创建虚拟机）
- 虚拟机配置
- 应用部署

**参考文档**: workflow/vm-deployment.md

---

### 5. 容器部署工作流 (container-deployment)

**描述**: 创建容器 -> 部署容器应用

**涉及步骤**:
- 通算任务提交（创建容器）
- 容器配置
- 应用部署

**参考文档**: workflow/container-deployment.md

---

### 6. 跨算力中心数据迁移工作流 (data-migration)

**描述**: 从一个算力中心迁移数据到另一个算力中心

**涉及步骤**:
- 数据下载
- 数据上传到目标中心

**参考文档**: workflow/data-migration.md

---

### 7. 批量任务处理工作流 (batch-processing)

**描述**: 批量提交多个任务并监控执行状态

**涉及步骤**:
- 批量任务提交
- 任务状态监控
- 结果汇总

**参考文档**: workflow/batch-processing.md

## 工作流创建规范

### 新增工作流流程

1. 分析用户需求，确定工作流名称和描述
2. 创建工作流详细步骤文档：reference/workflow/{name}.md
3. 在本文件中添加工作流条目
4. 更新相关参数和步骤文档
5. 经用户确认后执行工作流
6. 执行成功后完善文档

### 工作流文档命名规范

文件名采用小写字母，单词之间用连字符分隔：`workflow-name.md`

### 工作流ID规范

工作流ID与文件名一致，用于命令行调用：`jcc workflow run workflow-name`
