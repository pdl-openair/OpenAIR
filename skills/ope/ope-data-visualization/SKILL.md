# 数据可视化 (L2 — OPE)

## Goal
基于验证后的实验数据生成可视化图表，提炼关键洞察。

## Must Do
1. 根据数据特征选择合适的可视化类型
2. 生成高质量、可发表的图表
3. 从可视化中提炼关键发现与洞察
4. 输出可视化报告

## Must NOT
- 不得使用误导性的可视化方式
- 不得脱离数据凭空解读

## Output Contract
按 `schemas/ope/specs/visualization.md` 模板产出，使用 Write 工具写入当前任务工作区的 `report/visualization.md`。
