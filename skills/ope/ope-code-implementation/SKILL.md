# 代码实现 (L2 — OPE)

## Goal
根据实验设计与任务计划，实现实验所需的代码、脚本与工具链。

## Must Do
1. 按照实验设计实现核心实验代码
2. 编写数据处理与分析脚本
3. 确保代码可复现（版本控制、依赖锁定）
4. 输出实现说明文档

## Must NOT
- 不得偏离实验设计方案
- 不得遗漏代码可复现性要求

## Output Contract
按 `schemas/ope/specs/implementation.md` 模板产出，使用 Write 工具写入当前任务工作区的 `execute/code/implementation.md`。
