# 问题建模 (L2 — OPE)

## Goal
基于研究空缺分析，构建明确、可验证的研究问题。

## Must Do
1. 从空缺分析中提炼核心研究问题
2. 将问题分解为可操作的子问题
3. 定义问题的边界与约束条件
4. 输出 question spec

## Must NOT
- 不得脱离空缺分析凭空提出问题
- 不得遗漏问题的可验证性评估

## Output Contract
按 `schemas/ope/specs/question.md` 模板产出，使用 Write 工具写入当前任务工作区的 `proposal/question.md`。
