# 实验设计（L3 — OPE）

完成实验方案的技术设计，包括实验系统确立、算法方案设计、实验控制与统计规划。

## Method

### 子任务 1：实验系统确立

1. **环境选择**
   - 公开数据集：D4RL（MuJoCo/MiniGrid/Adroit）、RecoGym/ReplayBuffer、OpenAI Procgen 等
   - 仿真环境：Gym/Gymnasium、CARLA、Atari 等
   - 评估维度：数据质量、任务复杂度、计算成本

2. **变量定义**
   - 自变量：研究算法/估计器（新方法 + 基线方法 DM/IPS/DR/WDR/FQE）
   - 因变量：评估指标（MSE / Bias / Variance / 样本效率 / 覆盖度）
   - 控制变量：行为策略、数据规模、网络结构、随机种子

### 子任务 2：算法方案设计

1. **基线算法选择**
   - 经典基线：相关领域的主流 OPE 方法
   - 对比方法：本研究关注的主要对比方法
   - 选择依据：与假说契合度、文献对比基线、复现难度

2. **对比方法设计**
   - 消融实验：各方法组件的贡献（如 DR 中 IPS/DM 两支的独立贡献）
   - 敏感度分析：超参数（如行为策略正则强度、奖励归一化）对性能的影响
   - 跨域泛化：不同数据集/任务间的迁移性

3. **关键技术路径**
   - 实验流程图（文字描述）：行为策略估计 → 离线数据生成 → OPE 估计 → 评估对照真值

### 子任务 3：实验控制与统计规划

1. **控制组设置**
   - 不同基线方法的运行结果
   - 不同方法配置的对比
   - 分组依据：方法类型、数据分布、实验条件

2. **样本量与随机化**
   - 多随机种子：至少 5-10 个独立种子
   - 多环境配置：不同数据集、不同任务难度
   - 统计显著性：样本量计算、功效分析

3. **评估指标确定**
   - MSE（均方误差）：估计精度
   - Bias（偏差）：系统性误差
   - Variance（方差）：估计稳定性
   - 样本效率：数据利用效率
   - 覆盖度（Coverage）：行为策略对目标策略的覆盖程度

## Input

- 来自 `ope-rs-hypothesis-construction` 的假说列表与理论框架（`proposal/proposal.md`）
- 可选：用户已有的实验环境、基线算法、评估指标想法

## Output

按 `schemas/ope/specs/experiment_design.md` 模板产出，使用 Write 工具写入 `design/experiment_design.md`，结构：
- 实验系统确立（环境选择 + 变量定义）
- 算法方案设计（基线 + 对比 + 流程）
- 实验控制与统计规划（控制组 + 样本量 + 评估指标）
- 实验计划总览（阶段划分 + 资源需求）
- 立即可执行任务与待决策事项

## Constraints

- 系统化思维：环境/算法/统计是一个整体，不能孤立考虑
- 对照意识：每个实验都要有明确对照设计
- 可重复性优先：随机性控制（种子、配置版本化）必须写进方案
- 统计严谨性：样本量、功效分析要有依据，不拍脑袋
- 评估指标要与假说验证紧密对应
- 对假说中提及的前人工作（代码/论文）必须搜索并核实，用 AskUserQuestion 与用户确认准确性
- 结果落盘到 `design/experiment_design.md`
