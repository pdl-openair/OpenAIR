# 实验设计 (L2 — OPE)

## Goal
基于研究假设设计完整的实验方案，包括变量定义、对照设置与评估指标。

## Must Do
1. 根据假设定义自变量、因变量与控制变量
2. 设计实验组与对照组
3. 确定评估指标与统计检验方法
4. 输出 experiment design spec

## Must NOT
- 不得遗漏对照组设计
- 不得使用不合理的统计方法

## Output Contract
按 `schemas/ope/specs/experiment_design.md` 模板产出，使用 Write 工具写入当前任务工作区的 `design/experiment_design.md`。
