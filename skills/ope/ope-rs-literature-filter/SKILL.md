# 文献筛选（L3 — OPE）

对论文列表执行"快速筛选 → 深度精读 → 制作文献矩阵"三阶段处理。

## Method

### 子任务 1：标题/摘要快速筛选
对每篇论文用 `WebFetch` 抓取 arXiv/Scholar 摘要页，按用户标准（或推荐标准）逐篇判断相关性：

```markdown
| 论文标题 | 保留/排除 | 理由 |
|----------|-----------|------|
| ... | ✅ 保留 | 直接评估 OPE 估计器方差 |
| ... | ❌ 排除 | 在线策略评估，非离线场景 |
```

OPE 推荐筛选维度：
- 时间：近 3-5 年
- 方法族：DM（直接方法）/ IPS / DR / WDR / FQE / MAGENT 等
- 任务类型：离散动作 / 连续动作 / 稀疏奖励
- 数据集：D4RL、RecoGym、OpenAI Procgen 等
- 来源顶会：NeurIPS / ICML / ICLR / KDD / WWW

### 子任务 2：核心文献精读
对保留的论文逐篇抓取全文或详细摘要，提取结构化信息：
- 论文标题 & 作者
- 发表年份 & 来源
- 研究问题/动机
- 核心方法（估计器形式、超参数、收敛性假设）
- 主要贡献
- 使用的数据集与基准
- 主要结果/性能（MSE/Bias/Variance 等指标）
- 局限性
- 可改进方向

### 子任务 3：制作文献矩阵
将精读结果整理为 Markdown 表格与 CSV 双格式：

```markdown
| 论文 | 作者 | 年份 | 方法族 | 数据集 | 主要指标 | 局限 |
|------|------|------|--------|--------|----------|------|
```

### 工作流模式
- 模式 A（默认）：全流程（筛选→精读→矩阵）
- 模式 B：用户指定只做某个子任务

开始前用 AskUserQuestion 确认模式与筛选标准。

## Input

- 论文列表（来自 `ope-rs-info-retrieval` 的 `proposal/reference.md`，或用户直接提供）
- 可选：筛选标准
- 可选：指定子任务范围

## Output

按 `schemas/ope/specs/literature.md` 模板产出，使用 Write 工具写入当前任务工作区的 `proposal/literature.md`，包含：筛选结果表 / 精读摘要 / 文献矩阵 / 后续建议。

## Constraints

- 按顺序执行：先筛选、再精读、最后做矩阵，不跳步
- 精读论文不超过 15 篇，超出则分组进行
- 无法抓取的论文标注"信息有限"，不捏造内容
- 用户主导筛选标准；用户未给定时先推荐再执行
- 结果落盘到 `proposal/literature.md`
