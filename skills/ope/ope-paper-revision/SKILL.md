# 论文修订 (L2 — OPE)

## Goal
对论文初稿进行系统性审阅与修订，提升论文质量。

## Must Do
1. 从逻辑连贯性、表达准确性、格式规范性等维度审阅
2. 检查数据与图表的一致性
3. 记录修订意见并执行修订
4. 输出修订说明

## Must NOT
- 不得跳过审阅直接提交
- 不得忽略格式规范要求

## Output Contract
按 `schemas/ope/specs/revision_notes.md` 模板产出，使用 Write 工具写入当前任务工作区的 `report/revision_notes.md`。
