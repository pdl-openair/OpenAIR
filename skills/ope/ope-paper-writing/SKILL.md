# 论文撰写 (L2 — OPE)

## Goal
基于实验结果与可视化洞察撰写完整的研究论文。

## Must Do
1. 按目标期刊/会议格式组织论文结构
2. 撰写摘要、引言、方法、结果、讨论各部分
3. 嵌入可视化图表并编写图注
4. 规范引用参考文献
5. 输出论文初稿

## Must NOT
- 不得遗漏任何必要论文部分
- 不得伪造或夸大实验结果

## Output Contract
按 `schemas/ope/specs/paper.tex` 模板产出，使用 Write 工具写入当前任务工作区的 `report/paper.tex`。
