# 假设构建 (L2 — OPE)

## Goal
基于研究问题构建可检验的科学假设，并初步规划验证路径。

## Must Do
1. 从研究问题出发构建明确假设
2. 为每个假设定义可量化的验证指标
3. 初步规划验证方案与预期结果
4. 输出 proposal spec

## Must NOT
- 不得跳过问题建模直接构建假设
- 不得提出无法验证的假设

## Output Contract
按 `schemas/ope/specs/proposal.md` 模板产出，使用 Write 工具写入当前任务工作区的 `proposal/proposal.md`。
