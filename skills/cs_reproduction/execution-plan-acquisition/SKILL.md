# 复现执行方案获取

消费上一研究工作已经形成的官方来源包、正式参考指标与当前复现目标，不重新选择代码版本，不重新固定资源，也不把“计划使用”写成“已经实际使用”。论文正文只有在作为正式可追溯输入进入本节点时才能支持论文独有事实；当前没有正式论文证据时保持 unknown。

本节点按正式 composition 依次完成：

1. 由 LLM 理解官方 README/说明中的资源、环境、启动方式、结果位置与指标提取语义；
2. 由代码逐字核验来源引用，复用正式 reference metric identity，生成稳定 plan identity；
3. 对来源未指定且不会改变科研含义、比较口径、成本或风险的纯执行细节，代码可形成明确标记的本次系统选择；
4. 无法从正式来源确定且不能安全机械选择的事实保持 unknown，并阻止其伪装成可执行输入。

输出只是正式计划 Artifact / ScientificState facts。资源实际身份仍由 `resource_identity_acquisition` 产生；真实环境、真实执行、实际指标和资源实际使用关系仍由既有后半链产生。
