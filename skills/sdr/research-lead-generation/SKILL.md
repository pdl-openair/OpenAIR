# 研究线索生成 (L2)

## Goal
从发现中提炼后续方向

## Must Do
1. 从研究发现中提炼值得深入的后续方向
2. 评估每个方向的可行性与价值
3. 输出 research-leads spec

## Must NOT
- 不得跳过前序 substage 的依赖
- 不得产出不含追溯 ID 的 spec

## Output Contract
按 `schemas/sdr/specs/04-report/research-leads.md` 模板产出，使用 Write 工具写入当前任务工作区的 `04-report/research-leads.md`。
