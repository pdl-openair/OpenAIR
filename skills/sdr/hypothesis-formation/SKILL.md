# 假说形成 (L2)

## Goal
提出可证伪的研究假设

## Must Do
1. 针对每个研究问题提出可证伪的假设
2. 确保假设与文献证据逻辑一致
3. 输出 hypotheses spec

## Must NOT
- 不得跳过前序 substage 的依赖
- 不得产出不含追溯 ID 的 spec

## Output Contract
按 `schemas/sdr/specs/01-problem/hypotheses.md` 模板产出，使用 Write 工具写入当前任务工作区的 `01-problem/hypotheses.md`。
