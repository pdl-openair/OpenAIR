# 发现凝练 (L2)

## Goal
形成研究发现，构建追溯矩阵

## Must Do
1. 聚合经验证据，形成结构化研究发现
2. 构建发现→假设→问题的追溯矩阵
3. 输出 findings spec

## Must NOT
- 不得跳过前序 substage 的依赖
- 不得产出不含追溯 ID 的 spec

## Output Contract
按 `schemas/sdr/specs/03-experiment/findings.md` 模板产出，使用 Write 工具写入当前任务工作区的 `03-experiment/findings.md`。
